# Legacy — v0 (course project)

Original report: *Monocular Visual Odometry for Drone Navigation in Indoor Environment*
(Polytechnique Montréal, Navigation Systems course). Put `odometry.pdf` and the
original code here, unchanged, so the improvements in this repo can be compared
against it. Known issues are listed in [`../docs/postmortem.md`](../docs/postmortem.md).

Kept on purpose: the from-scratch FAST detector and ORB/BRIEF descriptor, which
are a good educational reference even though OpenCV's implementation is used in
the main pipeline for speed.
